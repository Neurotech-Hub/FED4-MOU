# FED4 MOU

This repository hosts the Memorandum of Understanding between the Washington University **Neurotech Hub** and the **Kravitz Lab** covering FED4 development, beta testing, distribution, and support, along with an interactive financial calculator that models the Neurotech Hub's investment recovery during the `EXCLUSIVE_UNITS` phase.

- [Read the MOU](MOU.md)
- [Open the FED4 Financial Calculator](https://neurotech-hub.github.io/FED4-MOU/)

The calculator lets you adjust per-device cost assumptions (PCB + battery, enclosure, assembly/programming) and visualizes the Neurotech Hub's cumulative cash position from initial engineering debt and stocked inventory through the first `EXCLUSIVE_UNITS` units sold. See the MOU for the full set of variables and contractual terms.
